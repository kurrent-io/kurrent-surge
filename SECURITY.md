# Security Policy

The Kurrent team takes the security of the Kurrent .NET SDK seriously. We appreciate the
efforts of security researchers and the community in responsibly disclosing vulnerabilities.

## Supported versions

The SDK is published as independent NuGet packages: `Kurrent.Surge` and `Kurrent.Surge.Core`.
Security fixes are released against the **latest published version** of each package. We
recommend always running the latest release.

| Version            | Supported          |
|--------------------|--------------------|
| Latest release     | :white_check_mark: |
| Previous releases  | :x:                |

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions,
or pull requests.**

Instead, use one of the following private channels:

- **Email** — [security@kurrent.io](mailto:security@kurrent.io)
- **GitHub Security Advisories** — use
  [Report a vulnerability](https://github.com/kurrent-io/kurrent-surge/security/advisories/new)
  to open a private advisory.
- **Security portal** — see [kurrent.io/security](https://www.kurrent.io/security#security)
  for company-wide reporting guidance.

Please include as much of the following as you can to help us triage quickly:

- The package and version affected.
- A description of the vulnerability and its potential impact.
- Steps to reproduce, or a proof-of-concept.
- Any known mitigations or workarounds.

## What to expect

- We will acknowledge your report within **3 business days**.
- We will provide an assessment and expected timeline for a fix after triage.
- We will keep you informed of progress and coordinate disclosure timing with you.
- With your permission, we will credit you when the fix is published.

Thank you for helping keep Kurrent and our users safe.
