# Voice Editor Memory

## Recurring violations
- This project's text tends to arrive with every banned pattern simultaneously (opener + closer + clichés + meta-narration + no contractions). Expect full rewrites, not polishes.
- "leverage", "utilize", "robust", "cutting-edge", "best practices", "streamline" appear frequently in draft text here.

## Score trends
- Inputs written in a marketing/chatbot voice score ~1-2 and need full rewrites. Budget for 2 passes.
- After a clean rewrite, pass 2 typically scores 9+. Three passes rarely needed.

## False positives
- "Here's what changed:" is a mild pointer but does not meet the meta-narration threshold by the scoring rules.
