# Git Conventional Commits Expert Skill

This skill provides comprehensive expertise in the Conventional Commits v1.0.0 specification, enabling Claude to help users create, validate, and analyze commit messages that follow this widely-adopted convention.

## What is Conventional Commits?

Conventional Commits is a specification for adding human and machine-readable meaning to commit messages. It provides an easy set of rules for creating an explicit commit history, making it easier to write automated tools for:

- Automatically generating CHANGELOGs
- Determining semantic version bumps
- Communicating changes to stakeholders
- Triggering build and publish processes

## Installation

1. Download the `git-conventional-commits-expert.zip` file
2. In Claude.ai, click on your profile icon
3. Select "Settings" → "Skills"
4. Click "Add skill" and upload the zip file
5. The skill will now be available for use in your conversations

## What This Skill Enables

Once installed, Claude can help you:

- **Write commit messages** - Get expert guidance on crafting properly formatted commits
- **Validate existing commits** - Analyze commit messages for specification compliance
- **Understand conventions** - Learn about commit types, scopes, and breaking changes
- **Set up standards** - Establish commit message guidelines for your team
- **Explain relationships** - Understand how commits relate to semantic versioning

## Example Usage

Simply ask Claude questions like:

- "Help me write a commit message for adding user authentication"
- "Is this commit message correct: 'Fixed bug in parser'?"
- "How do I indicate a breaking change in my commit?"
- "What's the difference between feat and fix commits?"
- "Help me set up commit conventions for my project"
