# Support

Thanks for using the Kurrent .NET SDK! This document explains where to get help.

GitHub issues are for **bug reports** and **feature requests** only — please use the
channels below for questions and general help.

## Asking questions and getting help

- **Documentation** — [developers.kurrent.io/clients](https://developers.kurrent.io/clients/)
  is the best first stop for guides, API references, and examples.
- **Examples** — runnable samples live in the [`examples/`](./examples) directory.
- **Discord** — join the community at [discord.gg/Phn9pmCw3t](https://discord.gg/Phn9pmCw3t) for
  real-time help and discussion.
- **GitHub Discussions** — ask questions and share ideas in
  [Discussions](https://github.com/kurrent-io/kurrent-surge/discussions).

## Reporting bugs and requesting features

- **Bugs** — open a [bug report](https://github.com/kurrent-io/kurrent-surge/issues/new?template=bug_report.yml).
- **Features** — open a [feature request](https://github.com/kurrent-io/kurrent-surge/issues/new?template=feature_request.yml).

Before opening an issue, please search [existing issues](https://github.com/kurrent-io/kurrent-surge/issues)
to avoid duplicates.

## Security issues

Please **do not** report security vulnerabilities through public GitHub issues. See
[SECURITY.md](./SECURITY.md) for how to report them privately.

## Commercial support

For commercial support, SLAs, and managed offerings, visit [kurrent.io](https://kurrent.io)
or contact your Kurrent account team.
