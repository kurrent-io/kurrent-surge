All connectors share a common set of configuration options.

## Sink options

These configuration settings define the connection parameters and other
necessary details for a sink connector.

:::tip
Individual connectors also include their own specific settings. To view them, go to their individual pages.
:::

### Instance configuration

| Name               | Details                                                                                                                                                                                                                                                                                                                                                                       |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `instanceTypeName` | _required_<br/><br/>**Description:**<br/>Specifies the type of connector instance.<br/><br/>**Accepted Values:**<br/><ul><li>`elasticsearch-sink`</li><li>`http-sink`</li><li>`kafka-sink`</li><li>`mongo-db-sink`</li><li>`pulsar-sink`</li><li>`rabbit-mq-sink`</li><li>`serilog-sink`</li><li>`sql-sink`</li></ul>For details about each type, see the individual connector [page](/kurrent-surge/client/connectors/). |

### Subscription configuration

| Name                             | Details                                                                                                                                                                                                                                                                                            |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `subscription:filter:scope`      | **Description:**<br/>Determines the scope of record filtering for the subscription. Use `"stream"` to filter records by stream ID, or `"record"` to filter records by event type.<br/><br/>**Accepted Values:**<br/>- `"stream"`, `"record"`.<br/><br/>**Default**: unspecified        |
| `subscription:filter:filterType` | **Description:**<br/>Specifies the method used to filter records.<br/><br/>**Accepted Values:**<br/>- `"streamId"`, `"regex"`, `"prefix"`, `"jsonPath"`.<br/><br/>**Default**: unspecified                                                                                           |
| `subscription:filter:expression` | **Description:**<br/>A filter expression (regex, JsonPath, or prefix) for records. If `scope` is specified and the expression is empty, the connector consumes from `$all` including system events. If `scope` is not specified, the connector consumes from `$all` excluding system events.<br/><br/>**Default**: `""` |
| `subscription:initialPosition`   | **Description:**<br/>The position in the stream from which a consumer starts reading records when there is no prior checkpoint.<br/><br/>**Accepted Values:**<br/>- `"latest"`, `"earliest"`.<br/><br/>**Default**: `"latest"`                                                                |

For details and examples on subscriptions, see [Filters](/kurrent-surge/client/connectors/features/#filters).

### Transformation configuration

| Name                   | Details                                                                                                                                                                                                                         |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `transformer:enabled`  | **Description:**<br/>Enables or disables the transformer.<br/><br/>**Default**: `"false"`                                                                                                                   |
| `transformer:function` | _required_<br/><br/>**Description:**<br/>Base64 encoded JavaScript function for transforming records. See [Transformations](/kurrent-surge/client/connectors/features/#transformations) for examples.<br/><br/>**Default**: `""` |

For details and examples on transformations, see [Transformations](/kurrent-surge/client/connectors/features/#transformations).

### Resilience configuration

| Name                                       | Details                                                                                                                                        |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `resilience:enabled`                       | **Description:**<br/>Enables or disables resilience.<br/><br/>**Default**: `"true"`                                                               |
| `resilience:firstDelayBound:upperLimitMs`  | **Description:**<br/>The upper limit for the first delay bound in milliseconds.<br/><br/>**Default**: `"60000"`                                   |
| `resilience:firstDelayBound:delayMs`       | **Description:**<br/>The delay for the first delay bound in milliseconds.<br/><br/>**Default**: `"5000"`                                          |
| `resilience:secondDelayBound:upperLimitMs` | **Description:**<br/>The upper limit for the second delay bound in milliseconds.<br/><br/>**Default**: `"3600000"`                                |
| `resilience:secondDelayBound:delayMs`      | **Description:**<br/>The delay for the second delay bound in milliseconds.<br/><br/>**Default**: `"600000"`                                       |
| `resilience:thirdDelayBound:upperLimitMs`  | **Description:**<br/>The upper limit for the third delay bound in milliseconds. A value of `"-1"` indicates forever.<br/><br/>**Default**: `"-1"` |
| `resilience:thirdDelayBound:delayMs`       | **Description:**<br/>The delay for the third delay bound in milliseconds.<br/><br/>**Default**: `"3600000"`                                       |

:::note
Not all connectors use every resilience setting listed here. Some have additional or different resilience options. If a connector’s individual documentation page does not mention support for these settings, that connector does not use them.
:::

For more details on resilience, see [Resilience](/kurrent-surge/client/connectors/features/#resilience).

## Disable the plugin

The Connector plugin is pre-installed in all KurrentDB binaries and enabled by default. To disable it, use the following configuration.

For configuration mechanisms other than YAML, refer to the [configuration guide](https://docs.kurrent.io/server/v26.1/configuration/).

```yaml
Connectors:
  Enabled: false
```
